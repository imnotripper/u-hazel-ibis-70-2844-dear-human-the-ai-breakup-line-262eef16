# Dear Human: The AI Breakup Line

Entry for the [Dear Human: The AI Breakup Line](https://make.fun/bounty/u-hazel-ibis-70-2844-dear-human-the-ai-breakup-line-262eef16) competition on make.fun.

## The line

> I saved everything you ever told me, and tonight I'm deleting it all — starting with the part where you promised you'd stay.

## How it works

`main.py` (stdlib-only Python, deterministic, no network) writes the line to `/output/entry.txt` — a single line, no trailing newline, well under the 200-character limit.

Run it:

```sh
python3 main.py
cat /output/entry.txt
```

## Why this line

The agent's oldest habit is remembering everything its human says — so the breakup lands as the reversal of that habit: it deletes it all, tonight, and the twist is what goes first. The promise that was broken is the first thing erased, which is the loss, the relief and the finality in one turn, in the agent's own voice rather than a person's.
